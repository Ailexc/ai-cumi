## 🎯 核心决策

### 为什么迁移？
1. **学习价值**：AG2 是对话/群聊式多 Agent 协作的行业标杆
2. **面试竞争力**：掌握 AG2 比 OpenClaw 更具面试竞争力
3. **技术矩阵**：CrewAI + LangGraph + AG2 覆盖主流 Agent 开发范式
4. **Python 能力**：补齐 Python Agent 开发能力

### 迁移范围
- **保留**：React 前端（基本不变）
- **重写**：Node.js 后端 → Python + FastAPI
- **替换**：OpenClaw 引擎 → AG2 引擎
- **新增**：GroupChat 编排、对话路由、记忆系统

### 时间与成本
- **总工期**：6-8周
- **总工时**：约 320 小时
- **技术栈**：Python + FastAPI + AG2 + React

# AiCumi 开发规范（2026-08-21 确认）

## 核心原则：学习导向

**这不是面向用户的产品，是个人学习作品。** 所有功能设计以"帮助学习"为第一目标。

### 设计理念

1. **透明优先**：不要隐藏内部实现细节
   - 思考链（thinking）要展示出来，不要剥离
   - 工具调用过程要可视化（调用了什么、参数是什么、返回了什么）
   - 错误信息要详细，方便学习和调试

2. **可探索**：功能要在 UI 上体现出来
   - 用户在操作过程中能感知到系统的能力
   - 每个功能都要有对应的 UI 入口
   - 避免"功能做了但看不到"的情况

3. **辅助学习**：多加辅助按钮和调试入口
   - "查看详情"按钮：点击可以看到内部状态、API 请求/响应
   - "测试"按钮：方便快速测试某个功能
   - "文档"按钮：点击可以看到相关概念的说明
   - 日志面板：实时显示系统内部事件

4. **渐进式披露**：信息分层展示
   - 默认展示简洁视图
   - 点击展开可以看到更多细节
   - 高级功能有明确的入口

### UI 规范

- 消息气泡：默认显示回复内容，点击展开可以看到思考过程
- 工具调用：显示为可折叠的卡片，展开可以看到完整调用过程
- 错误信息：显示友好的提示 + 详细的错误详情（可展开）
- 调试面板：右侧或底部可收起的面板，显示系统事件日志

### 代码规范

- 后端：Python + FastAPI + AG2
- 前端：React + TypeScript + Tailwind
- 测试：每个功能都要有对应的测试用例
- 文档：每个功能都要有简要说明
