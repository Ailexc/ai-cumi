# AiCumi 迁移至 AG2 开发实施计划

> 文档版本：v1.0
> 日期：2026-08-20
> 状态：规划中
> 总工期：6-8周
> 目标：完成从 OpenClaw 到 AG2 的迁移，实现对话/群聊式多 Agent 协作

---

## 一、项目概述

### 1.1 项目目标
将 AiCumi 从 OpenClaw 引擎迁移至 AG2 框架，实现：
1. **技术升级**：从 OpenClaw 迁移到 AG2，掌握行业标杆框架
2. **能力增强**：实现对话驱动的多 Agent 协作（GroupChat）
3. **学习价值**：补齐 Python Agent 开发能力，提升面试竞争力
4. **架构优化**：Python 后端 + React 前端，前后端分离更清晰

### 1.2 项目范围
- **保留**：React 前端（基本不变）
- **重写**：Node.js 后端 → Python + FastAPI
- **替换**：OpenClaw 引擎 → AG2 引擎
- **新增**：GroupChat 编排、对话路由、记忆系统

### 1.3 成功标准
| 标准 | 目标 |
|------|------|
| **功能完整性** | 实现当前所有核心功能（私聊、群聊、成员管理、技能市场等） |
| **性能** | 响应时间 < 2秒，支持 10 并发用户 |
| **稳定性** | 连续运行 24 小时无崩溃 |
| **学习价值** | 能独立使用 AG2 开发多 Agent 应用 |

| 情况 | 应急措施 |
