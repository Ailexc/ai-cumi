AiCumi 是什么

AiCumi 是一个「属于你个人的、云端的、全天候在线的 AI 助理团队」：用你自己的 Token，通过自有聊天窗口（私聊 / 群聊）指挥一群有性格、有技能、能真正干活的 AI 员工，管理面做到"点一点"完成员工编排与渠道配置。

一句话定位

打开 AiCumi 就像走进办公室 —— 侧栏是团队成员（可灵 / 小研 / 小码…），点谁就和谁聊；和每个成员的对话是持续的（像和同事的 IM），没有"新建对话"这种机器范式。

名字含义

  • Cumi：自造词，取"积累（accumulate）+ 陪伴（companion）"之意 —— 帮你积累知识、陪伴你长期办公的 AI 伙伴。
  • AiCumi：AI + Cumi，一个属于你、24/7 在线、有温度的私人 AI 助理团队。

为什么做这件事

这是一个个人学习作品（非商业产品），核心目标是：从后端开发转型 Agent 开发，面试有东西可讲。

🎯 项目目标

  • 功能全面对标业界：工具调用 / 记忆 / 群聊编排 / HITL / 可观测性 / 工作流 / 分布式 / RAG
  • 每个模块都有可讲的面试叙事与真实实现
  • 从「聊天机器人」升级为「能做事的 Agent」

📐 设计原则（学习导向）

  • 透明优先：思考链、工具调用过程可视化，不隐藏内部实现
  • 可探索：每个功能都有 UI 入口，避免"功能做了但看不到"
  • 辅助学习：详情 / 测试 / 文档按钮，日志面板实时显示内部事件
  • 渐进式披露：信息分层展示，默认简洁、点击展开细节
关键选择：引擎采用 AG2（微软 AutoGen 继任者，60K+ Stars）。曾基于 OpenClaw 壳层产品思路立项，2026-08-20 全面迁移至 AG2 —— 对话式多 Agent 协作的行业标杆，面试竞争力更强，且补齐 Python 侧的 Agent 开发能力。

如何运行

Docker 一键启动（开发与部署统一走 Docker + OrbStack）

docker compose up -d --build
docker compose ps
docker compose logs -f chat-server
前端 UIhttp://web.aicumi.orb.local
后端 API / Swaggerhttp://chat-server.aicumi.orb.local/docs
真实模式：在「模型管理」页添加模型并标记为默认 → 重启后端即进入真实对话；未配置模型时后端会明确报错提示，不 mock 兜底。

学习路线：怎么读这套文档

  1. 入门：先读本文档，建立功能全景；再到 02 · 架构总览 理解分层与数据流。
  2. 核心：按「对话 → 工具 → 记忆」的顺序读 03-05，这是 Agent 开发面试必问的三板斧。
  3. 工程化：读 06-07（HITL / 可观测性），理解生产级 Agent 的必备能力。
  4. 深度：读 08-09（工作流 / 分布式），了解编排与系统设计。
  5. 知识 + 底座：读 10-12（RAG / 模型中心 / 前端部署）。
