## 三、待实现能力（按优先级排序）

### 3.1 面试必讲能力（P0，必须做）

| 能力 | 差距 | 工作量 | 面试价值 | 说明 |
|------|------|--------|----------|------|
| **工具调用（FunctionTool）** | 🔴 大 | 1-2 周 | ⭐⭐⭐⭐⭐ | Agent 能调用搜索/代码/API，面试必问 |
| **记忆增强（向量检索）** | 🔴 大 | 1 周 | ⭐⭐⭐⭐⭐ | 跨会话记忆、Embedding 检索，面试高频考点 |

| **文件/代码处理** | 🟡 中 | 1 周 | ⭐⭐⭐ | Agent 处理实际任务的能力 |
| **可观测性（Tracing）** | 🟡 中 | 1 周 | ⭐⭐⭐ | Agent 执行追踪、调试能力 |

**理由**：这些能力体现了 Agent 系统的工程化水平，面试时能展示你对生产级 Agent 的理解。
