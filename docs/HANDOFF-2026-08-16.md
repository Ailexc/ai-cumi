## 一、本次会话回顾（做了什么）

2. **Memory 长期记忆启用**（2026-08-16）：

## 三、技术发现与坑（AiCumi 直接可用）

### OpenClaw 通道/插件
- 内置通道插件：飞书、Telegram、WhatsApp、Slack、Discord、Signal、LINE、Zalo、Microsoft Teams、Matrix、iMessage、IRC、Google Chat、Mattermost 等（`openclaw plugins list` 可查）
- **无微信/QQ**（硬约束）
- 插件可声明：工具、模型商、**通道（ChannelPlugin）**、钩子、HTTP 端点、CLI、memory
- **下一步关键**：研究 feishu channel 插件源码（`/app/src/channels/plugins/` 或 `extensions/feishu`），确认自定义 channel 接口 → 写 Web Chat 通道

### 多租户
- OpenClaw 源码**无 multi-tenant**，单租户/实例；真隔离 = 每租户一个容器实例

### OpenClaw Memory
- 两个 memory 插件：`memory-core`（文件型，零配置）+ `memory-lancedb`（向量库+auto-recall，需 OpenAI key+原生依赖，国内不可用）
- 国内 embedding 解法：`agents.defaults.memorySearch = {provider:"openai", model:"text-embedding-v3", remote:{baseUrl:"https://dashscope.aliyuncs.com/compatible-mode/v1", apiKey:<dashscope key>, batch:{enabled:false}}}`（batch 必须关）
- 记忆存储：各 agent workspace 的 `MEMORY.md` + `memory/*.md`，索引库 `~/.openclaw/memory/<agent>.sqlite`
- CLI：`openclaw memory status / index --force / search <q> --agent <id>`

### 浏览器（OpenClaw CN）
- `browser.attachOnly:false` = OpenClaw 自拉 chrome；持久化 profile 会损坏导致 connectOverCDP 挂起
- 自愈补丁 + 看门狗已装（详见旧仓库记忆 `aliyun-ecs.md`）

### 运维坑（操作上）
- `pkill/pgrep -f` 模式会自匹配杀自己 → 用 `18[8]00` 括号技巧 + `/proc/<pid>/exe` 校验
- 远程脚本用 heredoc 管道（`cat <<EOF | ssh ali 'bash'`），别用深层引号嵌套
- 本地同步要在本机 scp，不能放 ssh 管道里
