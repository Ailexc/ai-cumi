## 五、待验证项（需你人工确认）

### 5.1 浏览器端到端（最重要）
以下链路**代码已实现、编译通过，但未经真实浏览器点击验证**：

1. 启动（见 §六）
2. 左侧功能栏 → 点击「文档」→ 应显示文档中心：4 个分类分组 + 卡片网格（图标/标题/描述）
3. 点击任意卡片 → 进入详情页：顶栏（返回/分类徽章/标题）+ 左侧「本文目录」+ 右侧文档内容
4. **滚动文档内容** → 左侧目录应跟随高亮当前章节（IntersectionObserver 实现）
5. **点击左侧目录项** → 文档应平滑滚动到对应位置
6. 返回按钮 → 回到文档中心；切换其他板块再切回文档 → 详情状态应重置
7. 窄屏（<1024px）→ 左侧目录隐藏（lg 断点），文档内容仍可阅读

```bash

# 然后访问
open http://web.aicumi.orb.local
```

```bash

# vite.config.ts 的 proxy 指向 3100, 需先改为 8000:
```
