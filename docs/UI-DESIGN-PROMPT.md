## 角色设定

你是一位世界级的资深产品设计师，服务过 ChatGPT、Claude、Linear、Notion、Slack 等产品的界面设计。请为下面的产品设计一整套完整、现代、可直接指导前端实现的界面方案。你输出的是**具体、可执行的设计规范**（布局、组件、色彩、字体、间距、状态），不是概念草图。

## 产品背景

**产品名**：AiCumi —— 个人云端 24/7 的私人 AI 助理团队。
**一句话**：用户在自有聊天窗口里，和自己的一群 AI 员工（可灵=前台秘书、小研=调研专员、小文=内容运营）私聊和群聊，像用 Slack/飞书 指挥一个团队，但对话对象是 AI。
**核心功能（优先级从高到低）**：
1. 私聊（用户 ↔ 单个 AI 员工）
2. 群聊（用户 ↔ 多个 AI 员工，@ 指定员工）
3. AI 员工目录（谁是员工、什么角色、在不在线）
4. 会话历史（云端同步）
5. （后续）管理面：新建员工、技能配置、渠道设置

## 设计目标

- **情感**：温暖、专业、有"被陪伴"的感觉；不是冷冰冰的机器工具。
- **气质**：克制的高级感（参考 ChatGPT/Claude 的排版与留白），但结构上要有"团队工作台"的产品感（参考 Slack/飞书）。
- **必须避免**：模板感、廉价感（详见"禁忌清单"）。

## 风格关键词

温暖白底 · 近黑文字 · 低饱和强调色 · 发丝细边框 · 克制阴影 · 大留白 · 几何头像 · 系统字体 · 安静微动效

## 对标参考

- 聊天质感 / 排版：ChatGPT 桌面版、Claude、Perplexity
- 团队结构 / 工作台感：Slack、飞书、Linear
- 空状态 / 品牌：Vercel、Notion

## 核心页面：聊天主界面（三栏布局）

总宽度满屏，高度满屏，三栏结构：

```
┌────────────┬────────────┬────────────────────────┐
│ ① 员工导航   │ ② 会话列表  │ ③ 聊天窗               │
│  220px     │  300px     │  剩余（消息区居中 ≤780px）│
└────────────┴────────────┴────────────────────────┘
```

### 栏 ①：员工导航（220px）
- 顶部：品牌区（几何渐变 logo + "AiCumi" + 副标"私人 AI 助理团队"）
- 分组"AI 员工"：每个员工 = 渐变几何头像（32px 圆角方块）+ 名字 + 角色副标 + 状态点（在线绿/忙碌黄/离线灰）
- 分组"群聊"：群聊项 = 群图标（主色软底 + # 图标）+ 群名 + 成员数 + 未读徽标
- 底部：我的工作区 + 设置图标
- 员工 3 个：可灵（前台秘书）、小研（调研专员）、小文（内容运营）；群聊 2 个：全员、项目组

### 栏 ②：会话列表（300px）
- 顶部：**醒目的主操作按钮「新建对话」**（主色实底、白字、+ 图标、圆角 10px、全宽、置顶、带轻阴影）
- 分组"今天" / "最近"：会话项
- 会话项 = 头像（员工/群）+ 标题 + 最后消息预览（1 行省略）+ 右侧时间 + 未读徽标（主色圆形数字）
- 选中态：浅灰底（非品牌色）；悬停：更浅灰；项内边距充足（上下 10px），项间距 ≥2px

### 栏 ③：聊天窗（剩余）
- 顶栏（62px）：会话头像 + 标题 + 在线状态 + 副标（角色）；右侧 2 个图标（搜索、更多）
- 消息流：消息区居中 max-width 760px，左右留白 ≥32px；消息间距 24px；上方有一个轻量问候区（大标题 + 一句副标）
  - **AI 消息**：左侧渐变头像（30px）+ 名字 + 时间 + 白色气泡（1px 发丝边框，圆角"6px 16px 16px 16px"）
  - **用户消息**：右侧主色实底白字气泡（圆角"16px 16px 6px 16px"），max-width 78%
- 底部 Composer（悬浮圆角容器，max-width 与消息区一致）：
  - 一行：附件图标 + 输入框 + 发送按钮（主色圆角方块）
  - 第二行小字：左侧"发送给 可灵 · 模型名 ▾"，右侧"⌘ Enter 发送"
  - 输入框聚焦时边框加深 + 极淡外发光

## 需一并输出的其他页面/状态

1. **聊天主界面**（上面详细描述的那页，最高优先级）
2. **空状态**（新用户，无会话）：居中的品牌 logo + 大标题（如"欢迎使用 AiCumi"）+ 副标 + 3 个建议动作卡片；底部仍是 Composer
3. **会话列表的加载/空态**：无会话时的占位（图标 + 引导文案 + 新建按钮）
4. **移动端（≤768px）适配**：三栏如何折叠（隐藏员工栏 → 隐藏会话列表 → 只剩聊天窗 + 返回按钮）
5. **（概念级）管理面**：员工管理页的视觉方向（卡片式员工列表 + 状态），只需风格示例，不必完整

## 设计令牌（请按此范围发挥，可微调但保持气质）

```css
/* 背景（暖白阶梯） */
canvas:  #f7f7f8;
surface: #ffffff;          /* 栏/卡片/气泡 */
hover:   rgba(0,0,0,.04);
active:  rgba(0,0,0,.07);

/* 文字（近黑） */
primary:   #1a1b1e;
secondary: #5f6368;
muted:     #9aa0a6;

/* 边框（黑低透明发丝线，禁止灰色 #d1d5db） */
border: rgba(0,0,0,.07);
borderStrong: rgba(0,0,0,.12);

/* 主色（低饱和，可三选一，我推荐靛蓝） */
靛蓝:  #5e6ad2（hover #4a56c4，soft #eef0fb）
陶土:  #cc785c（Claude 风，更暖）
暖炭:  #0d0d0d（黑白极简）

/* 状态色 */
在线 #53b559 / 忙碌 #e8a13a / 离线 #c4c4c4

/* 阴影（克制，≤10% 黑，短距） */
0 2px 10px rgba(0,0,0,.10) 级别

/* 圆角 */
按钮/卡片 10px；气泡 16px（不对称尾角）；头像 32% 圆角

/* 字体 */
系统栈：-apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", sans-serif
正文 15px / 行高 1.65；标题 600 字重；侧栏 13px

/* 间距（4px 网格） */
消息间距 24px；栏内 padding 12-16px；消息区左右 ≥32px
```

## 员工视觉（头像 mark）

每个员工一个**几何头像**：柔和渐变圆角方块（约 8px 圆角）+ 居中白色线性图标。**禁止 emoji、禁止字母+彩色底**。
- 可灵（前台秘书）：靛蓝→紫渐变，星芒图标
- 小研（调研专员）：青→蓝渐变，罗盘/放大镜图标
- 小文（内容运营）：橙→浅橙渐变，笔/文档图标
- 群聊：主色软底 + #（hash）图标

## 禁忌清单（务必避免）

1. 禁止大渐变按钮/气泡/输入框（渐变只出现在 logo 和员工头像）
2. 禁止高饱和电光蓝紫满屏、禁止大圆角（≥24px 的整块圆角）
3. 禁止 emoji 当图标/头像/状态点（状态用 CSS 圆点，图标用线性 SVG）
4. 禁止有色相的大阴影（如 rgba(30,50,100,.14)）
5. 禁止灰色边框 #d1d5db 类（用黑色低透明发丝线）
6. 禁止拥挤：间距宁大勿小，宁可留白不可堆叠
7. 禁止"新建"类主操作做成小按钮/幽灵按钮——它是本产品最高频动作，必须醒目
8. 禁止把聊天做成一堆卡片/框套框；层次靠背景亮度 + 留白
9. 动效保持安静：hover 仅背景微变；消息入场 200ms 淡入上移；typing 三点呼吸
